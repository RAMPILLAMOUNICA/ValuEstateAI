 📌 Overview

ValuEstate AI is a full-stack web application that predicts property value using multiple real-world factors such as location, size, age, and legal clarity.

It provides:

* 📊 Market Value Range
* 💸 Distress Value
* 📈 Resale Potential Index
* ⏳ Estimated Time to Liquidate
* ⚠️ Risk Analysis
* 🎯 Confidence Score


 🧠 How It Works

1. User enters property details in the frontend
2. React sends data to FastAPI backend
3. Backend processes data using valuation logic
4. Results are returned and displayed instantly
